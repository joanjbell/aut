# J. Bell Price — Visual Threads v3.3

This is a focused follow-on to the structural refresh v3.2. It removes the botanical sprig and builds visual continuity from details cropped from the author's existing artwork.

## What changed
- Removed the sprig illustration completely; no diamonds or ornamental flourishes were added.
- Turned the homepage archive-note preview into a larger, restrained image plate using a detail from *A Healing Light*.
- Added small, cropped artwork thumbnails to the homepage theme index.
- Added a compact artwork detail and caption to the right side of each theme page's heading.
- Added nine optimized JPEG details derived from the existing paintings, avoiding repeated downloads of large original art files.
- Kept the sage/ivory palette, Cormorant Garamond + Inter, core typography, section rhythm, selected works, and bookshelf intact.
- Added a stylesheet version parameter to the homepage and theme pages to reduce stale CSS/cache mismatches.

## Apply the update
Back up your deployed site, then upload/replace `index.html`, `css/styles.css`, all `theme-*.html` files included in this patch, and the new `images/theme-previews/` folder. The update has not been published to the live website.
